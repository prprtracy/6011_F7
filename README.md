# SOEN 6011 - F7 Power Function

This repository contains my individual SOEN 6011 Software Engineering
Processes project for the assigned function **F7: x raised to y**.

## Deliverables

- [Delivery 1](./D1) - persona, requirements, candidate algorithms, algorithm
  selection, and a textual user interface.
- [Delivery 2](./D2) - from-scratch numerical implementation, Tkinter GUI,
  custom exception handling, independent verification, updated requirements
  and documentation, screenshots, GAI evidence, and presentation material.

## Repository structure

```text
6011_F7/
|-- D1/         # Delivery 1 design and implementation
|-- D2/         # Delivery 2 implementation and evidence
`-- README.md   # Repository overview
```

Delivery 1 and Delivery 2 are preserved in separate directories so the
project's iterative development remains visible.
